The workflow

From upload to audited render in six clean moves.

Every step is fail-closed. A bad file never reaches the GPU, a client never sets a price, and every action leaves a trace you can actually defend.

01◈

Ingest

Magic-byte validation and ClamAV scanning reject polyglots, spoofed extensions and malware before decode.

fail-closed
02⌁

Sanitize

Pixels are re-encoded and EXIF/GPS metadata is stripped. Device fingerprints never reach the render worker.

metadata scrub
03≋

Queue

An atomic Redis leaky-bucket limiter protects GPU capacity and is keyed to the token hash, not the user.

atomic limiter
04✦

Render

ControlNet + SDXL run on non-root, read-only GPU workers with dropped capabilities and a seccomp profile.

GPU shield
05◇

Pay

Hosted Checkout, 3DS2 and HMAC-verified webhooks keep raw card data out of your stack entirely.

PCI SAQ A
06◎

Audit

Tenant RLS, uniform 404 IDOR guards and PII-redacted structured logs make every action traceable.

audit trail
